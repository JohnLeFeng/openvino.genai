## Run Model Using OpenVINO GenAI

OpenVINO GenAI supports the following diffusion model pipelines:
- [`Text2ImagePipeline`](https://docs.openvino.ai/2026/api/genai_api/_autosummary/openvino_genai.Text2ImagePipeline.html) for creating images from text prompts.
- [`Image2ImagePipeline`](https://docs.openvino.ai/2026/api/genai_api/_autosummary/openvino_genai.Image2ImagePipeline.html) for modifying existing images based on prompts.
- [`InpaintingPipeline`](https://docs.openvino.ai/2026/api/genai_api/_autosummary/openvino_genai.InpaintingPipeline.html) for selectively replacing portions of images using masks.

#### Attentive Eraser object removal

Attentive Eraser is a prompt-free `InpaintingPipeline` mode for removing masked objects with SD1.5, SD2, and SDXL Base models. The primary prompt must be empty. `prompt_2` is used only by SDXL's second text encoder and must also be unset or empty. Negative prompts are unsupported, `guidance_scale` must be `1.0`, and `rm_guidance_scale` controls removal guidance.
